# Projektziel

Die Landingpage soll modern, professionell und hochwertig aussehen, aber sich optisch weiterhin am offiziellen Odoo-Stil orientieren. Odoo ist ein Unternehmen die schon eine bestehende Website Hat. Hier hast du als orientierung zum Stil eine schon erstellte landingpage: „Odoo Beratung & Implementierung – Ihr Partner in Deutschland“ (Frontend), die kern elemente wie farben und das was die website so eigen macht sollst du beibehalten.

Die Landingpage soll am Ende vollständig nutzbar sein, nicht nur technisch vorbereitet.

Wichtige Ziele:
- sehr schnelle Ladezeiten
- hohe Frontend-Performance
- saubere und übersichtliche Code-Struktur
- wartbarer Code für andere Entwickler
- gute SEO-Basis
- einfache Erweiterbarkeit über Strapi CMS
- vollständiger initialer Content in Strapi
- fertige Darstellung im Frontend

Das Frontend soll leichtgewichtig bleiben und keine unnötige Komplexität enthalten.

Bitte bevorzuge einfache, performante und verständliche Lösungen statt unnötig komplexer Architektur.
