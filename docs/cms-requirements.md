# Strapi CMS Anforderungen

Die Content-Types sollen sauber strukturiert und problemlos erweiterbar sein.

Strapi soll hauptsächlich zur Inhaltsverwaltung genutzt werden:
- FAQs
- Blog
- Hero-Texte
- Leistungen
- SEO-Inhalte
- Kontaktinformationen

Aufgabe für Strapi:
Lege passende Content-Types an oder verbessere bestehende Content-Types.
Füge vollständige Demo-/Startinhalte über Strapi ein, damit die Landingpage direkt fertig wirkt.

Erstelle mindestens:
- Homepage-Inhalte mit Hero-Titel, Subtitle, CTA-Texten und SEO-Daten
- 5 bis 6 Leistungen rund um Odoo-Beratung und Odoo-Entwicklung
- 6 bis 8 FAQs
- 2 bis 3 Blogartikel oder Blog-Teaser
- globale Kontaktinformationen
- Footer-Inhalte
- sinnvolle Meta Titles und Meta Descriptions

Wichtig:
Normale redaktionelle Inhalte sollen über Strapi gepflegt werden.
Code soll nur für Struktur, API-Anbindung, Layout und Logik genutzt werden.
Wenn Inhalte per Script oder API eingefügt werden, dokumentiere klar, wie das funktioniert.
